LUNA — це односторінковий лендінг для концептуального продукту: левітуючого місячного світильника з дерев'яною основою. Проєкт створено як демонстрацію front-end навичок без використання фреймворків — лише чистий HTML, CSS і JavaScript. Сайт не є рекламою реального товару і не продає нічого. Це портфоліо-робота.


HTML5 — семантична розмітка без фреймворків. CSS3 — кастомні змінні, grid, flexbox, анімації. Vanilla JS. Google Fonts — Inter та Space Grotesk.


Темна і світла тема з перемикачем у навбарі та плавним переходом через CSS-змінні. 3D-обертання продукту — drag мишкою або тач на мобільному, автоматичне обертання у спокої. Scroll reveal анімації — елементи з'являються при прокрутці через IntersectionObserver. Повністю адаптивний дизайн з мобільним меню. Тепла золотисто-бурштинова палітра під атмосферу місячного сяйва. Base64 зображення — фото вбудоване напряму в HTML без зовнішніх запитів. Email-форма з валідацією та feedback-станом.


Кольорова палітра побудована навколо теплого золота і глибокого темного фону — щоб передати атмосферу нічного сяйва місяця. Заголовки набрані Space Grotesk — геометричний, впевнений шрифт. Основний текст — Inter, читабельний і нейтральний. 3D-ефект реалізований через CSS perspective і transform без WebGL.

Це концептуальний проєкт. Продукт LUNA не існує в реальності, не продається і не рекламується. Фото використане виключно як візуальний матеріал для демонстрації верстки.
